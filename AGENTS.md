# Working agreement and project orientation

Read `~/.claude/CLAUDE.md` in full. It is the canonical working agreement; do not
copy its protocol into this repository.
If it is missing or unreadable, report that fact and ask the owner for the
canonical agreement before making changes; do not invent a replacement protocol.

For automation and personal-operations work, read
`docs/automation-ops-2026-09-05.md` for the intended outcomes and improvement test,
then `docs/contracts/README.md` for the observed jobs and their contracts.
Challenge proposed mechanisms against the owner outcome. If that outcome or a
necessary preference is unclear, ask the owner while continuing independent work.

Historical architecture and assessment documents are context, not proof of the
current deployment. Verify the actual entrypoint before changing a running job.
